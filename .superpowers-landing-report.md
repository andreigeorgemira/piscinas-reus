# Piscinas Reus - landing page build report

## Sections built and layout family

1. **Nav** (`src/components/nav.tsx`) - single line, `h-16 md:h-[72px]`, sticky/fixed, backdrop blur. Logo + 4 links + 1 CTA. Mobile: hamburger (Phosphor `List`/`X`) toggles a full-width dropdown panel (`useState`, no scroll listener).
2. **Hero** (`src/components/hero.tsx`) - asymmetric 12-col grid, text `col-span-7` / image `col-span-5`, mobile stacks image-then-text (`order-1`/`order-2`). `min-h-[100dvh]`, `pt-24`. 4 text elements total (headline, subtext, 2 CTA labels), no eyebrow. Motion: opacity/translate-y and opacity/scale entrance, gated by `useReducedMotion()`.
3. **Services** (`src/components/services-bento.tsx`) - asymmetric bento: large image+gradient-caption cell (2x2), medium image-over-text cell, and a solid pine card with a Phosphor icon for maintenance (no photo needed there, per spec). Mobile collapses to single column stack.
4. **How the work goes** (`src/components/process-timeline.tsx`) - vertical narrative with a `md:sticky` intro column (heading + supporting photo) and a right-hand ordered list of 5 named steps (no "Fase N" labels), each revealed with `whileInView` (`viewport once`, reduced-motion aware). Step ordinal is `sr-only` only, never visible.
5. **Gallery** (`src/components/gallery-masonry.tsx`) - CSS-columns masonry (1/2/3 columns responsive) with varied aspect ratios per image, no captions. Two placeholder testimonials in a 2-card row beneath it (marked as placeholder in a code comment in `site-config.ts`).
6. **Service area** (`src/components/service-area.tsx`) - horizontal scroll-snap strip of 6 town cards (photo + gradient scrim + icon/distance/name/note), not a bulleted list. Different family from both the bento and the masonry.
7. **FAQ** (`src/components/faq-accordion.tsx`) - accordion, `useState` for open index, Phosphor `CaretDown` rotation, 6 real homeowner questions.
8. **Contact** (`src/components/contact-form.tsx` + `contact-section.tsx`) - name/email/phone/message/service-type fields, labels above inputs, local `useState` success screen, `// TODO: POST to /api/leads once the backend lands` left in place. No network call.
9. **Footer** (`src/components/footer.tsx`) - nav links, service towns, contact details, repeated CTA, copyright.

## Palette tokens (`src/app/globals.css`)

Light: `--color-bg:#f2f4f0` `--color-bg-alt:#e6e9e2` `--color-surface:#ffffff` `--color-text:#16241e` `--color-text-muted:#4b564f` `--color-border:#d6dad1` `--color-brand:#1e3a32` `--color-brand-dark:#14261f` `--color-accent:#c2603c` `--color-accent-strong:#a6502f`.
Dark (`prefers-color-scheme: dark`): `--color-bg:#14261f` `--color-bg-alt:#192f27` `--color-surface:#1e3a32` `--color-text:#eceff0` `--color-border:#2e453c` `--color-accent:#d97a4c` `--color-accent-strong:#c2603c`.
No cyan/turquoise, no warm-paper neutrals. Single accent (terracotta) used for CTA fills, one icon color, one underline rule, one icon per town card - never a second hue.

Contrast check: solid CTA buttons always use `--color-accent-strong` (`#a6502f`) with white text, which computes to ~5.5:1 white-on-fill contrast (WCAG AA pass for normal text) in both themes. The lighter decorative `--color-accent` is only ever used for icons/underlines or large display text (~3.7-4.2:1 against page backgrounds), never for body-size text.

Shape lock: Tailwind's default `rounded` (4px) is used for every card, image, button and input; nothing else.

## Pre-flight self-check against the hard rules

- Zero em dashes / en dashes anywhere in visible copy (grepped, none found).
- Eyebrow count: 0 (well under the 3 budget) - no small uppercase tracked labels used anywhere.
- No section numbering, no visible "Fase N" labels (step ordinal is `sr-only` only), no scroll cues, no decorative status dots, no locale/weather strips, no version labels, no fake-precise invented stats (durations and town distances are given as ranges/approximate real geography, not fabricated business metrics), no `·` separators, no pills over photographs (bento/service-area captions use a gradient scrim, not a badge shape), no photo-credit captions.
- No three-equal-card feature row (services bento is deliberately asymmetric; the 6-town strip and 2-card testimonial row are not "three equal cards").
- No `window.addEventListener('scroll')` anywhere; scroll-triggered reveals use Motion's `whileInView`.
- CTA label is `Pedir presupuesto` everywhere it appears (nav, hero primary, footer). Hero secondary is a distinct action (`Ver proyectos`, scrolls to gallery). Contact form's submit button (`Enviar solicitud`) is a distinct in-flow action, not a competing marketing CTA. A contact-section heading that originally used "Hablemos..." was reworded to "Cuéntanos tu proyecto" to avoid any overlap with the banned CTA-label set.
- All animations above trivial intensity call `useReducedMotion()` and skip the initial transform when reduced motion is requested.
- Mobile collapse declared per section (grid to single column, sticky columns disabled, horizontal scroll-snap strip stays usable on touch, hamburger nav). `max-w-7xl mx-auto` + `px-4` used consistently.
- Two testimonials use realistic Catalan/Spanish names and towns, explicitly marked as placeholder pending real quotes in a code comment in `src/lib/site-config.ts`.
- No statistics, certifications, awards or customer counts invented.
